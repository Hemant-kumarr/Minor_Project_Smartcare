About SmartCare AI

Built to Make Healthcare Accessible

SmartCare AI is a student-built healthcare consultation platform developed as a B.Tech CSE minor project. It demonstrates full-stack web development, REST API design, MongoDB database management, role-based authentication, and integration with Google's Gemini AI.

The platform connects patients with verified doctors for online consultations, appointment booking, and digital prescription management – all in one secure, easy-to-use system.
